# 公開サイトの表示・検証

トップページ (`index.html`) は、日本語要約を読めるカード表示とキーワード検索、解析スケール・分野・実行環境などの絞り込みを提供します。24件ずつ表示し、検索条件・並び順・ページ番号はURLに保持します。「項目リンク」は1件に直接移動するURLです。アーカイブ済み項目は初期状態では除外せず、状態を明示します。

## データの更新

検索ページは `src/human_data_lib/data/libraries.json` を直接読み込みます。件数・更新日・フィルター候補も同じJSONから計算するため、表示専用データの複製や追加の生成手順はありません。既存の `make catalog-page`、`make validate`、`make test` を引き続き実行してください。

`catalog.md` と各文書は従来どおりJekyllがHTMLに変換します。共通レイアウト `_layouts/default.html` は検索ページへの導線・読みやすい本文幅・横にスクロールできる表を提供します。既存の全件表や索引・アンカーは変更しません。JavaScriptを無効にしている場合や読み込みが失敗した場合も、全件表へのリンクが利用できます。

## ローカルでの確認

依存パッケージの追加はありません。検索ページは次の静的サーバーで確認できます。

```bash
python3 -m http.server 8765
# http://localhost:8765/ をブラウザで開く
node --test tests/catalog-ui.test.mjs
make validate
make test
```

`file://` ではブラウザのfetch制約があるため、HTTPサーバーを使ってください。文書ページの `.html` リンクとLiquidレイアウトを確認するにはJekyllビルドまたはGitHub Pages上での確認が必要です。標準のPython HTTPサーバーはMarkdownやLiquidを変換しません。

確認する操作: 検索、複数条件の組み合わせ、0件時のクリア、ページ送り、URL再読み込み、ブラウザの戻る・進む、項目リンク、詳細の開閉、キーボード操作、狭い画面での表示。フィルターの件数は全カタログに対する件数で、条件を追加した後の件数は結果欄に表示します。

検索語・条件はブラウザ内で処理され、外部検索サービスには送信しません。URLには検索条件が含まれるため、機微な情報は入力しないでください。
